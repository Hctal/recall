INSIDE .GIT

OBJECTS--Without objects, Git has no history.

HEAD--points the current branch we working on (main)
 
 REFS/--stores ref like heads/main file , feature file, tags/ (branches and tags are ref to commit)

 CONFIG--repo specific settings (username , email, remote repo)

INDEX--staging area--git index after add everything stored here

GIT OBJ (3)
    BLOB--FILE CONTENT
    TREE--ORGANIZES FILE AND FOLDERS
    COMMIT--AUTHOR,DATE ,COMMIT MESSAGE,PARENT COMMIT,POINTER TO TREE -(NO CONTENT JUST TREE REPRESENTATION OF FOLDER AND FILE PATHS)
